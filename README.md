# HACKMAP-hackUMBC

RetrieversPath prototype for helping college students map interests to career opportunities.

## Run locally

This project is a static web app. Open `/home/runner/work/HACKMAP-hackUMBC/HACKMAP-hackUMBC/index.html` in a browser, or serve the folder:

```bash
cd /home/runner/work/HACKMAP-hackUMBC/HACKMAP-hackUMBC
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Features

- Collects student profile inputs (degree path, niche, projects, and career goal)
- Supports student-email sign-in with configurable school domains
- Generates tailored opportunities with salary ranges
- Recommends related careers
- Creates a step-by-step career plan with project and research guidance
- Uses accessible labels, semantic structure, and high-contrast UI
